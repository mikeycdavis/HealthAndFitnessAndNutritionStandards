## What

The `node:test` suite with a mutation test per guard, the README and INSTRUCTIONS, the
architecture reference and its canonical Mermaid source, and a CI workflow with no install step.

## Why

A guard nobody has watched fail is a guard nobody knows works. Every guard here has a test that
reintroduces the exact defect it exists to catch and asserts the guard fails.

## Notes

CI accepted exit 4 visibly, with the reason written into the workflow rather than hidden in a shell
expression, for as long as the repository's own verdict was honestly `NOT_EVALUATED`. Mapping that to
0 would have been the exact false green the whole system is built to avoid.

The allowance was removed under ST-06, after four human attestations made the verdict `COMPLIANT` on
its merits. The gate is now `npm run check` alone.
